# Clinician Web

Archived placeholder for the earlier clinician web milestone.

The current production frontend lives in `frontend/`. The old static RAG
chatbot demo was removed when the unused FastAPI RAG API was deleted.

Use the live RAG endpoints through the Express backend:

- `POST /api/v1/patient/rag/chat`
- `POST /api/v1/patients/:patientId/rag/chat`
